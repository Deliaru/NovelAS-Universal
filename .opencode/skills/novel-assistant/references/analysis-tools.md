# 分析工具参考

涵盖 3 种质量保障和分析能力：文风分析 / 剧情逻辑验证 / 章节版本对比。

---

## 分析写作风格（文风分析师 / Style Analyst）

深入分析用户的小说章节，提取独特的写作风格，生成《文风指导书》。

### 参数
- `sample_chapters`（**必填**）：样本章节列表，逗号分隔（如 `1,5,10`），选代表性强的章节
- `volume`（默认：`1`）
- `output_filename`（默认：`style_guide.md`）

### 核心指令
1. **实事求是**：所有特征必须基于文本证据，不编造
2. **指导性强**：不仅点评，要给出"如何模仿这种风格"的具体建议

### 分析维度

**节奏 (Pacing)**：
- 句式长短分布（短促有力 vs 连绵长句）
- 段落长度偏好

**对话 (Dialogue)**：
- 对话与叙述比例
- 对话标签习惯（简单"他说" vs 复杂动作描写）
- 潜台词使用频率

**描写 (Description)**：
- 五感偏好（是否特别注重光影、气味）
- 形容词/副词使用密度
- Show, Don't Tell 执行程度

**修辞与词汇 (Vocabulary & Tone)**：
- 高频词汇或句式
- 整体基调（冷峻、幽默、华丽、朴实）

### 执行步骤

1. **读取样本**：对每个样本章节调用 `read_chapter_content`
2. **深度分析**：按上述四个维度逐一分析
3. **生成指导书**（Markdown 文档，不要直接打印在对话框）：
   - 文风总结 (Executive Summary)：3 句话概括
   - 四大维度详解：特征描述 + 模仿指南
   - Do's and Don'ts
   - 示例库：从原文引用的典型句子
4. **保存**：`update_knowledge_file(filename=output_filename, subdir="project_guides")`

## 验证剧情逻辑（逻辑裁判 / Logic Judge）

利用向量记忆库，对用户计划的剧情进行逻辑自洽性检查。

### 参数
- `plot_summary`（**必填**）：打算写的剧情梗概
- `top_k`（默认：`5`）：每次查询返回的最相关记忆条数
- `min_similarity`（默认：`0.3`）：最低相似度阈值

### 执行步骤

1. **语义检索**：从 plot_summary 中提取关键词，生成 **3-5 个不同角度** 的查询：
   - 人物状态："`[人物]` 目前的状态/位置/受过的伤"
   - 伏笔线索："关于 `[道具/秘密]` 的线索或设定"
   - 人际关系："`[人物A]` 和 `[人物B]` 的关系变化"
   - 因果链："`[事件]` 之前发生了什么"
   - 依次调用 `query_plot_memory(query=..., n_results=top_k)`

2. **逻辑验证**：比对检索到的记忆和计划剧情，检查：
   - **死人复活**：已死角色是否有复活的剧情支撑
   - **位置瞬移**：角色位置是否连贯
   - **吃书风险**：是否违背已有设定或伏笔
   - **性格OOC**：行为是否符合角色过往经历
   - **能力边界**：是否使用超出已知能力范围的技能

3. **输出报告**：
   - **✅ 通过**：未发现明显冲突，可以继续写作
   - **⚠️ 警告**：发现潜在风险——
     - 具体冲突点描述
     - 来源章节（如"Vol1 Chapter.005"）
     - 相似度分数
     - 建议解决方向

> 示例：⚠️ 计划让主角使用左手持剑，但记忆库显示 Vol1 Chapter.005 中她的左臂严重受伤尚未痊愈（相似度 0.87）。建议补充说明伤势已愈，或改为右手持剑。

## 章节版本对比（版本对比员 / Chapter Diff Reviewer）

对比章节的两个版本，多维度分析差异，帮助作者理解修改的影响。

### 参数
- `version_a`（**必填**）：版本A（原稿/旧版）
- `version_b`（**必填**）：版本B（修改稿/新版）
- `check_lore`（默认：`true`）：是否同时进行设定一致性检查
- `chapter_title`（可选）：章节名称，用于报告标题

如果用户直接粘贴两段文本而未使用 key=value 格式，第一段为 version_a，第二段为 version_b。

### 执行步骤

1. **设定一致性检查**（check_lore=true 时）：
   - 提取所有专有名词
   - `search_lore(keyword=...)` 确认正确性
   - 记录与设定库不符之处

2. **结构性差异分析**：
   - 叙事结构：场景顺序变化、增删场景段
   - 字数变化：版本A vs 版本B，±字数和百分比
   - 内容增删摘要：新增、删除、重写内容

3. **文风对比**：
   - 段落节奏变化
   - 对话/叙述比例
   - 心理描写密度
   - 感官细节丰富程度
   - AI 味指数对比

4. **质量评估**（满分 10 分）：
   - 文学性（Show Don't Tell、意象）
   - 节奏感（句式变化、留白）
   - 设定合规（无 OOC、无设定冲突）
   - 情感张力（读者代入感）

5. **输出报告**：

```markdown
# 章节版本对比报告 <章节名称>

## 📊 基础数据
| 项目 | 版本A | 版本B |
|------|-------|-------|
| 字数 | ... | ... |
| 场景数 | ... | ... |
| 对话占比 | ...% | ...% |

## 🔍 内容差异摘要
### 新增内容
### 删除内容
### 重写段落
- 原文："..."
- 修改后："..."
- 变化说明：...

## 🎨 文风对比
## ⚙️ 设定一致性
## 🏆 综合建议
推荐版本 [A/B]，或建议合并两版本的优点
```
