# 契约单曲发布方案

## 歌曲信息
- **歌曲名**：契约 (Yakusoku / やくそく)
- **所属作品**：SORANORI 第二卷主题曲
- **演唱视角**：悠星束
- **核心角色**：悠星束、遥·阿斯特洛菲尔
- **主题**：羁绊、对抗命运、双向救赎、生死契约
- **情感基调**：深情、坚定、悲壮中带着希望
- **核心歌词**：
  - 「契約してよ　ずっと一緒だって」
  - 「二人でいるんだって　そうでなければ意味がないの」

## 一、发布时机建议

### 方案 A：周五晚间黄金档（推荐）
- **推荐日期**：2026-04-25
- **推荐时段**：20:00-21:00
- **选择理由**：
  - **剧情进度**：第二卷已完结，读者对束与遥的羁绊理解最完整，情感承接最强。
  - **粉丝期待**：周五晚间是二次元内容消费高峰，适合情绪浓度高的角色歌首发。
  - **平台算法**：B 站周五晚间音乐区整体流量较高，利于首发扩散与周末持续发酵。
- **优势**：
  - 能借周末形成二次传播。
  - 有利于粉丝连续循环播放、转发和二创。
- **风险**：
  - 同时段竞争内容较多，预热必须充分。

### 方案 B：周日下午温情档
- **推荐日期**：2026-04-27
- **推荐时段**：15:00-16:00
- **选择理由**：
  - 情绪型内容在周日下午更容易被完整听完。
  - 同时段竞争压力相对较小。
- **优势**：
  - 更适合核心粉丝沉浸式聆听。
- **风险**：
  - 总体曝光峰值可能低于周五晚间。

## 五、回复方案

### 回复原则
- **语气**：克制、简短、像企划号，不抢观众的情绪解释权
- **内容**：优先接住观众提到的歌词、剧情感受、角色关系，再轻度延展
- **避免**：避免“谢谢支持冲三连”“这段超刀/超甜”等过热口语与站内套话

### 首小时执行
- 回复前 20 条评论
- 优先回复提到歌词、世界观、角色关系、合作方的评论
- 置顶评论固定为“歌词/瞬间”引导，不额外解释剧情

### 回复建议（按评论气质来回，不要机械套用）

#### 1. 夸歌 / 夸旋律
```text
谢谢你喜欢。
```

```text
能被你听见就很好。
```

#### 2. 提到某句歌词
```text
这一句我也很喜欢。
```

```text
看到你也记住了这一句。
```

#### 3. 提到“约定 / 契约”的变化
```text
是，“约定”和“契约”已经不是同一种东西了。
```

```text
写到这里的时候，已经回不去最开始的那个“约定”了。
```

#### 4. 问是否有剧情对应
```text
有对应。
```

```text
这一部分还是留在故事里比较好。
```

#### 5. 提到角色关系、说很痛 / 很喜欢
```text
她们之间一直都很复杂。
```

```text
能让你这样感觉到就够了。
```

#### 6. 没看原作但被吸引
```text
那就太好了。
```

```text
也欢迎从这里开始认识她们。
```

#### 7. 提到凋叶粽 / RD-SOUNDS
```text
这次也非常感谢凋叶粽。
```

```text
RD-SOUNDS 的诠释真的很珍贵。
```

#### 8. 想看后续 / 想补原作
```text
欢迎。
```

```text
后面的故事也还在继续。
```

### 不同评论类型的处理建议
- **高质量剧情解读**：简短肯定即可，不抢答，不给标准答案
- **误读但无恶意**：只接情绪，不急于纠正设定
- **催更 / 催后续**：回应“后续也会继续推进”，不空口许诺具体日期
- **刷梗式评论**：少量点头即可，不把评论区带成玩梗场

### 不建议出现的回法
- “如果这段故事与旋律也打动了你……”
- “欢迎留下你最喜欢的一句歌词……”
- “感谢大家支持，我们会继续努力”
- 任何明显像客服话术、品牌号套话、站内运营黑话的句子

### 发布后 24 小时复盘重点
- 播放量与收藏率
- 评论中高频提到的歌词句子
- 评论对“约定 / 契约 / 归来 / 枷锁”四个母题的聚焦度
- 是否有观众因歌曲而回流原作 / 对企划本身产生兴趣
- 是否需要追加一条“歌词片段解读”或“感谢支持摘录”动态

### 长期运营
- **歌单方向**：建立 SORANORI 音乐合集。
- **二创方向**：鼓励翻唱、填词、手书、剧情向剪辑。
- **关联内容**：后续可联动推出歌词解析、剧情向短片、角色关系解读。

## 六、风险评估与安全检查

### 剧透检查
- **检查结果**：⚠️ 轻微剧透
- **说明**：
  - 歌词本身已承接第二卷核心情感关系。
  - 若简介直接提及章节关键转折，会增加剧透程度。
- **建议**：
  - 对外公开文案尽量少写具体剧情节点。
  - 将更深入的剧情解析放到置顶评论或后续动态中。

### 设定一致性
- **检查结果**：✅ 符合设定
- **说明**：
  - 歌词情绪与束、遥在第二卷后期确立的“双向契约”高度一致。
  - 不存在明显角色口吻偏差。

### 敏感内容
- **检查结果**：✅ 无明显敏感内容
- **说明**：
  - 当前海报、歌词与定位均以情感表达为主，风险较低。
